# TubeP3

TubeP3 is a clean, AMOLED-first Android frontend for `yt-dlp` and `FFmpeg`, utilizing Termux as a local background execution engine.

- **Audio Quality:** Highest quality MP3 audio conversion (`--audio-quality 0`, 320 kbps).
- **Metadata & Artwork:** Automatically embeds title, artist metadata, and thumbnail.
- **Output:** Downloads directly to the Android device's standard **Downloads** folder.
- **Zero Terminal Hassle:** No need to open Termux or type commands during daily usage.
